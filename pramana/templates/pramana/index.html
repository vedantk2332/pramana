Pramana uses a dual-verification system: (1) Retrieval-Augmented Generation (RAG) queries a local FAISS vector store of official documentation (such as trees.pdf) to ground answers in verified texts, and (2) Python AST static analysis validates syntax and rules without running arbitrary code.
